# 仓库系统 · Cloudflare 部署教程（Worker + Static Assets + D1，最新推荐）

本教程教你怎么把 `cloudflare/` 这个版本部署到 Cloudflare。它现在是**一个 Worker 脚本**（`src/worker.js`）：

- 既处理后端 `/api/*` 接口，数据存 **D1（serverless SQLite）**；
- 又通过 **Workers Static Assets** 把前端 `public/index.html` 直接托管出来；
- 无需登录，所有人打开网址就能用。

> 为什么是「Worker」而不是「Pages」：Cloudflare 现在推荐新项目用 **Worker + Static Assets**，Pages 已进入维护模式。用 Worker 是官方主推形态，且原生支持 GitHub 自动部署。

---

## 一、准备

- 一个 Cloudflare 账号（免费）：https://dash.cloudflare.com/sign-up
- Node.js ≥ 18（本机已有；仅本地预览 `wrangler dev` 需要）
- 不需要装数据库软件（D1 在云端）

---

## 二、创建 D1 数据库

数据库名 `warehouse`：

- 控制台 → **Storage & Databases → D1 SQL → Create database**，名字填 `warehouse`，创建。
- 进入数据库详情，复制 **database_id**（形如 `xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx`）。
- 打开 `cloudflare/wrangler.jsonc`，把 `database_id` 换成你刚复制的值。

> 表结构（`items` / `movements` / `settings` / `backups`）会在**第一次访问时自动建好**，不用手动跑 SQL。

---

## 三、本地预览（先在自己电脑跑通，可选）

```bash
cd G:/仓库网站/cloudflare
npm install            # 装 wrangler（devDependency）
npx wrangler dev      # 启动本地，默认 http://localhost:8788
```

浏览器打开：点 ＋ 加物品、取出、备份导出，确认能用。本地预览默认连云端同一个 D1（`database_id` 已填好），所以预览录入的数据部署后也在。

> 想用完全独立的本地库测试：把 wrangler.jsonc 里的 D1 绑定临时指到一个本地 sqlite 文件，或用 `npx wrangler dev --d1 DB=./local.sqlite`。

---

## 四、正式部署（两种方式任选）

### 方式 A：命令行（最直接）

```bash
cd G:/仓库网站/cloudflare
npx wrangler login          # 浏览器授权
npx wrangler deploy         # 读取 wrangler.jsonc，部署 Worker + 静态资源 + D1 绑定
```

完成后给一个网址：`https://warehouse-cloudflare.<你的子域>.workers.dev`

### 方式 B：网页端 + GitHub 自动部署（推荐，见 `Git自动部署教程.md`）

连上 GitHub 仓库后，以后 `git push` 就自动重新部署，连命令行都不用敲。

---

## 五、绑定自己的域名（可选）

Workers & Pages → 你的项目 → **Settings → Triggers → Custom Domains / Routes**，添加域名并按提示加一条 CNAME。等几分钟生效。

---

## 六、把旧数据迁过来

前端自带导入/导出：旧系统备份页「导出 JSON」→ 新系统备份页「导入 JSON」。注意导入会整体替换当前数据。

10 人的小仓库，连零头都用不到。

---

## 八、一个重要提醒（国内访问）

Cloudflare **免费版在中国大陆访问可能不稳定、被限速甚至打不开**（控制台能进，但网站实际访问不稳）。Cloudflare 的中国 CDN 是企业版付费能力。

- 用户**在海外**或能走代理 → 这版直接可用；
- 用户**都在国内要稳定直连** → 更推荐走 `edgeone/` 版。

---

## 目录结构速查

```
cloudflare/
├── public/index.html    # 前端（无需改动，API 调 /api）
├── src/worker.js        # 后端：/api/* 接口 + 托管静态资源，数据存 D1
├── wrangler.jsonc       # Worker + D1 + 静态资源配置（填 database_id）
└── package.json         # dev / deploy 脚本
```

部署核心三步：**建 D1 `warehouse` 填 id → `wrangler login` → `wrangler deploy`**（或连 GitHub 自动部署）。
